# Queens Park Academy - Boomerang Lost & Found Portal

A React web application built with Vite and Tailwind CSS for managing school lost & found inventory, staff messaging, student claims, and PTA stock management.

## 🚀 Quick Start Guide

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (version 18 or higher recommended).

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR-USERNAME/queens-park-boomerang.git
   cd queens-park-boomerang
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 🛠️ Features & Taxonomy Logic
- **Glasses & Accessories Tab:** Contains sunglasses and small personal accessories (e.g. earbud cases) isolated from standard Electronics.
- **"All Items" Aggregator:** Clear overview listing all lost items regardless of category.
- **Direct Staff Messaging:** Fixed header access to message staff directly (**Bhargav Kandala**).
- **PTA Expiry Countdown:** Tracks 30-day expiration for unclaimed low-value items transferring to PTA Stock.
